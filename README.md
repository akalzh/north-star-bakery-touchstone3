This folder contains the updated multi-page website for Sophia Touchstone 3.

Files:
- index.html
- products.html
- about.html
- contact.html
- styles.css
- bakery image/media assets

Design system:
- Cream #FFF8F0
- Brown #6B3E26
- Peach #D8A17F
- Charcoal #2F2A26
- Fonts: Georgia/Times New Roman for headings and Arial/Helvetica for body text

Responsive layout:
- Mobile-first CSS
- Flexbox for navigation, hero, product cards and other layouts
- Media queries at 720px and 1000px
